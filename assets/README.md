# Hero video

The homepage currently uses the supplied real-estate tour MP4 from the project root.

Recommended export:

- MP4 (H.264), 1920×1080 or 2560×1440
- 15–30 seconds, seamless loop
- No audio track (the browser video is intentionally muted)
- Web optimized, ideally under 12 MB
- Keep important subjects away from the extreme edges because the video uses `object-fit: cover`

Until the file is added, the homepage uses the architectural poster image set on the `<video>` element.
